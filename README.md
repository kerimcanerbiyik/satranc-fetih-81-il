# Satranç ile Türkiye Fethi (81 İl - Gerçekçi Harita Sınırları)

## Kurulum ve Çalıştırma
1. Klasörü VS Code içinde açın.
2. Eski sunucu çalışıyorsa durdurun (`Ctrl + C` veya `npx kill-port 3000`).
3. Yeni sunucuyu başlatın: `npm start` (veya `node server.js`)
4. Tarayıcıdan `http://localhost:3000` adresine gidin.
